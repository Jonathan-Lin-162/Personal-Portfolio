# Personal Portfolio

A responsive personal portfolio website built with **React, JavaScript, and Vite** to showcase my software development projects, technical skills, education, and professional experience.

🌐 **Live Website:** [Jonathan Lin's Portfolio](https://jonathan-lin-portfolio.vercel.app)

## About

I'm Ye Naing (Jonathan) Lin, a Computer Systems Technology student at the British Columbia Institute of Technology (BCIT), interested in software development and building full-stack web applications.

This portfolio highlights my technical background, personal and academic projects, and experience. It also provides access to my resume and professional profiles.

## Technologies Used

- **Frontend:** React, JavaScript, HTML, CSS
- **Build Tool:** Vite
- **Deployment:** Vercel
- **Version Control:** Git and GitHub

## Features

- Responsive layout for desktop, tablet, and mobile devices
- Smooth scrolling and interactive navigation
- About Me and technical skills sections
- Personal and academic project showcase
- Work experience and education
- Resume access
- GitHub and LinkedIn integration

## Getting Started

To run this project locally:

### 1. Clone the repository

```bash
git clone https://github.com/Jonathan-Lin-162/Personal-Portfolio.git
cd Personal-Portfolio
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal.

### 4. Build for production

```bash
npm run build
```

## Deployment

This portfolio is deployed using **Vercel**, with automatic deployments from GitHub.
